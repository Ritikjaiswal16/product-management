## Technologies and Libraries used:
This project is build with:
* **Webpack**: A powerful module bundler for Javascript applications, used to bundle, optimize, and manage assets.
* **React**: Javascript library for building user interfaces.
* **React Router**: For client-side routing.
* **Axios**: For handling API requests.
* **Bootstrap && React-Bootstrap**: A popular CSS framework for responsive and mobile-first web design.
* **Bootstrap Icons**: A collection of open-source icons designed to work seamlessly with Bootstrap.
* **Formik**: A flexible and easy-to-use library for handling forms, validation, and submission in React.
* **Moment.js**: A javascript library for parsing, validating, manipulating, and formatting dates and times.
* **React Select**: A flexible and customizable dropdown/select component for React applications.
* **Boxicons**(Needs to be eliminated): A lightweight and customizable icon library with a wide range of icons for web applications.
